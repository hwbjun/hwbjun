## 👋 소개

**RAG 파이프라인**과 **LLM 에이전트**를 설계하고 프로덕션에 배포하는 AI 엔지니어입니다.  
하이브리드 검색, SSE 스트리밍, QLoRA 파인튜닝 등 실무 중심의 AI 시스템을 구축합니다.
